🛡️ Isolated Cybersecurity Homelab | Windows Target & Linux Attacker

An isolated virtual cybersecurity research environment built using Oracle VM VirtualBox, featuring a Windows target machine and a Linux-based attacker machine. This homelab is designed for hands-on learning, penetration-testing fundamentals, network security research, and understanding the relationship between offensive and defensive cybersecurity.

The entire environment operates within a virtual Internal Network, providing a controlled space for security experimentation without intentionally exposing the lab machines to external networks.
